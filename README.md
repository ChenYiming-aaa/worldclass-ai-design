# worldclass-ai-design

把 AI 从"安全、平均、紫渐变"的委员会设计，推进到有独立视觉身份的设计。

源方法：Anshu Chimala（前 Apple 软件工程与设计团队负责人，12 年）发表于 Lenny's Newsletter 的
*How to turn your AI into a world-class designer*（2026-09-01）。

- `SKILL.md` 是给 Agent 的执行入口（心智模型 + 三阶段流程 + 自检清单）
- 本 README 给人看：安装、目录结构、一个完整跑通的实战案例

## 安装

```bash
# 从 GitHub 克隆（用户级，所有项目可用）
git clone https://github.com/ChenYiming-aaa/worldclass-ai-design.git ~/.workbuddy/skills/worldclass-ai-design

# 或项目级
git clone https://github.com/ChenYiming-aaa/worldclass-ai-design.git <项目>/.workbuddy/skills/worldclass-ai-design
```

## 目录结构

```
worldclass-ai-design/
├── SKILL.md                        # 入口：心智模型 + 三阶段流程 + 自检清单
├── references/
│   ├── prompts.md                  # 原文提示词库（英文 verbatim + 中文说明）
│   ├── critic-loop.md              # 评审循环纪律、停止条件、模型分配
│   ├── media-generation.md         # 图像/视频接入、API key 安全红线、降级方案
│   ├── ai-tells.md                 # 减法删除测试 + AI 痕迹两遍清单
│   └── edges-and-failures.md       # 研究局限 + 全部故障排查表（唯一出处）
├── assets/
│   └── design-brief-template.md    # 阶段 1 的设计简报模板
└── scripts/
    └── seed-string.sh              # 外部随机种子生成器
```

渐进式披露：Agent 先读 `SKILL.md`，只在需要时加载对应 reference。

## 实战案例：纸带流水（单文件记账工具）

一个用本流程完整跑通并已上线的真实示例，**本仓库的 GitHub Pages 就是它**：
源码在本仓库 `docs/` 目录，Pages 直接托管。

**在线体验：<https://chenyiming-aaa.github.io/worldclass-ai-design/>**

下面记录**这个示例是怎么做出来的**：从一句中文触发语，到有独立身份的界面。

### 第 1 步 · 触发（用户原话，一句就够）

> 设计一个有创意的日记+账本记录日常的前端网页，要求加入模拟数据用来填充图表等（如果有）。

人的触发语用母语即可；发给执行 Agent 与评审 Agent 的风格指令全部用 `references/prompts.md`
的英文 verbatim 原文，**不翻译**——独特设计的先验锚定在英文语料里。

### 第 2 步 · 随机种子 → 三个方向（技术 1、2）

用 `scripts/seed-string.sh` 生成 3 个种子，从**字符结构**（不是字面）各读出一个方向：

| 种子开头 | 读到的结构 | 推出的方向 |
|---|---|---|
| `2FEg9yoOwEY…` | `F` 每 8 位出现一次、周期性全大写爆发 | **连续纸带** —— 一条不断裂的时间轴 |
| `4yR1DdNM4S…` | 大小写成对交替、数字单点散落 | **双轴坐标网格** —— 每笔记录是坐标系上的点 |
| `TN31oI0fBh…` | `I0` 母题重复两次、句尾全大写段 | **索引卡档案** —— 编号 + 归档标签 |

三个方向的构图骨架、字体类别（等宽点阵 / 手写衬线 / 打字机）、明暗关系全部不同——不是换皮。用户选定**连续纸带**。

### 第 3 步 · 简报写成"世界"（技术 2）

> 一台老式热敏收银机。按下按钮，纸带从出纸口里缓缓吐出来，
> 上面同时印着这一天花掉的钱和这一天写下的字。

这个"世界"直接决定了后面所有选择：配色只能是**纸与墨**、强调色只能是**热敏红**、
字体只能是**等宽**、分隔只能用**虚线**；卡片网格 / 渐变 / 玻璃拟态从简报起就不成立。

### 第 4 步 · 截图评审抓到的问题（技术 3）

用真实截图（Chrome headless，1x / 2x 双像素密度）跑了两轮，评审基线是
"顶级设计工作室会怎么执行'热敏纸带'这个方向"。实质发现都不是"好不好看"，而是**可证伪的缺陷**：

- 纸纹被 `background-size: 512px` 在 1x 屏降采样 2:1，颗粒被平均掉——纸纹等于白生成 → 改 768px 并重新校准振幅
- 次级文字对比度仅 **2.72:1**（低于 4.5:1）→ 重新定值，逐项复核到 4.96:1

### 第 5 步 · 材质与收尾（技术 4、6、7）

- 纸纹用**图像生成 + 后处理**（高通去斑块、无缝化），拒绝用 CSS 渐变造材质
- 对每个元素做删除测试（删掉后信息不丢 = 删）
- 视觉 + 文案两遍 AI 痕迹清单；H1 / 主按钮 / 空状态 / 错误态四处关键文案人工重写

### 后续迭代

同一方向继续长成完整工具：收支增删改查、组合筛选、月度预算、
打印机逐行出纸动画（rAF 驱动 + WebAudio 合成音效）、CSV/JSON 导入导出——
所有功能都与"热敏纸带"这个隐喻一致，布局重构时也守住了它。

完整设计决策记录（种子推导、每轮评审的处置表、已知取舍）在案例项目的 `DESIGN-BRIEF.md`。

### 这个案例验证了什么

- 一句中文触发语 + 英文 verbatim 流程提示词，可以稳定产出**有独立身份**的界面
- 评审循环的价值在可证伪的缺陷（对比度、降采样、冗余元素），不在主观审美争论
- 简报写成"世界"之后，后续所有迭代自然不会漂回默认模板
